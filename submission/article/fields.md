SentinelFlow: a Cybersecurity Incident Triage Agent with Strands Decider 2B and Amazon Bedrock

Description (max 512 characters):
SentinelFlow triages simulated security alerts in real time. Strands Decider 2B classifies each alert against a written policy in one forward pass and routes it to INVESTIGATE, ESCALATE, LOW_PRIORITY, or HUMAN_REVIEW. Amazon Bedrock (Nova Pro) handles the conversation and incident summary. Built with the AWS User Group Madurai Strands Decider hackathon kit.
